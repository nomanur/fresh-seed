🎯 Core Features

Instead of executing `php artisan migrate:fresh --seed` which wipes your entire database structure and takes forever, Fresh Seed allows you to surgically refresh and seed specific database tables instantly.

🎯

Surgical Refresh

Truncate or safely delete only the table you specify, leaving other database tables perfectly untouched.

🔀

Multi-Table Support

Refresh multiple tables sequentially using a simple comma-separated table parameter.

📂

Table Presets/Groups

Define group presets in the config to run a sequence of related truncates and seeds with one command.

🗺️

Interactive Picker

Run the command without options to select which table(s) to refresh using an interactive picker.

🔍

Dry-Run Preview

Validate your targets by running a full preview sequence without altering any table data.

🛡️

Safe Delete Mode

Utilize transaction-safe standard DELETE statements instead of TRUNCATE to avoid implicit commits.

🚀 Getting Started

Learn how to install and register the package inside your Laravel application.

Installation

Install the package through Composer as a development dependency:

Terminal 
composer require --dev nomanurrahman/fresh-seed

The service provider will automatically register itself using Laravel's Package Discovery.

Publishing the Configuration

To register table presets/groups or custom connections, publish the configuration file to your config folder:

Terminal 
php artisan vendor:publish --provider="Nomanurrahman\FreshSeed\FreshSeedServiceProvider" --tag="config"

🛠️ CLI Commands & Arguments

Here are all the available options for the console command:

Option Description
--table= One or more comma-separated tables to refresh. (e.g. --table=users,posts).
--seeder= Explicit seeder class to run (only valid when refreshing a single table).
--group= The name of a pre-configured table group defined in your config.
--safe Use DELETE FROM instead of TRUNCATE to avoid implicit commits.
--dry-run Print the operations that would be executed without modifying database records.
--database= Database connection to use (defaults to default connection).
--force Force the operation to bypass production warnings.

Examples

Refresh a single table (guesses the seeder automatically):

Bash 
php artisan fresh:seed --table=users

Refresh multiple tables sequentially:

Bash 
php artisan fresh:seed --table=users,posts,comments

Specify a custom seeder explicitly for a single table:

Bash 
php artisan fresh:seed --table=users --seeder=CustomUserTableSeeder

🗺️ Interactive Selection Mode

If you don't supply the --table or --group option, the package automatically queries the database schema to fetch all available tables and launches an interactive multi-select console component.

Shell Interaction

🛡️ Safe Deletion & Dry-Run Mode

Learn about constraint handling, safe transaction modes, and previews.

Safe Deletions with --safe

⚠️ Implicit Database Commits

In MySQL and PostgreSQL, running a TRUNCATE statement causes an implicit commit, meaning database transactions cannot roll it back. Furthermore, standard developers might lack table-lock TRUNCATE privileges in highly protected database environments.

Running the command with the --safe option instructs the package to perform a standard DELETE FROM table query instead. This operates within database transaction limits and ensures elevated safety.

Bash 
php artisan fresh:seed --table=users --safe

Dry-Run Preview Mode

Preview exact command executions safely before running migrations on critical datasets:

Bash 
php artisan fresh:seed --table=users,posts --safe --dry-run
Output 
[Dry Run] Would delete all records from table: users
[Dry Run] Would seed table using seeder: Database\Seeders\UserSeeder
[Dry Run] Would delete all records from table: posts
[Dry Run] No seeder found or specified for table: posts

🔌 Targeting Custom Connections

Enterprise and multi-tenant applications utilize secondary database connections. Target specific connections seamlessly using the --database option:

Bash 
php artisan fresh:seed --table=users --database=tenant_1

This automatically ensures constraint disabling, truncation queries, and internal Laravel seeder scopes run entirely on connection tenant_1.

📂 Presets and Group Configurations

Instead of manually keying in list tables, define reusable table presets directly in your published config/fresh-seed.php configuration file.

Groups support simple arrays (which auto-guess standard seeders) and key-value pairs (which explicitly assign a specific class path):

config/fresh-seed.php 
return [
    'groups' => [
        'auth' => [
            'users' => 'Database\\Seeders\\UserSeeder',
            'roles' => 'Database\\Seeders\\RoleSeeder',
            'permissions' => 'Database\\Seeders\\PermissionSeeder',
        ],
        'blog' => ['posts', 'comments'], // Guesses PostSeeder and CommentSeeder
    ],

    'connection' => null, // Configure a default fallback connection
];

Run group presets using the --group= flag:

Bash 
php artisan fresh:seed --group=auth

🔍 Seeder Detection Conventions

When an explicit seeder is not supplied, Fresh Seed checks both the root class path and the standard Database\Seeders\ namespace, following Laravel conventions in this specific order:

  1. Studly Case Table Plural Seeder: For table name product_items, it searches for ProductItemsTableSeeder.
  2. Studly Case Table Singular Seeder: It searches for ProductItemSeeder.
🚨 Validation Constraint

Specifying a custom seeder via the --seeder option is only valid when refreshing a single table. Passing multiple tables with a single seeder option throws a validation check to avoid seeding incompatible data columns into different tables.
